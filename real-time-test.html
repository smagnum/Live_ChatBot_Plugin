🔬 Testing Instructions

  1. Open Both Windows: Click the links above to open both visitor chat and admin dashboard in separate windows/tabs
  2. Login to Admin: Use your WordPress credentials to connect to the admin dashboard
  3. Send Visitor Message: In the visitor chat, send a message like "Hello, I need help!"
  4. Check Admin Dashboard: Within 5 seconds, the conversation should appear in the client list (auto-refresh)
  5. Open Conversation: Click on the client in the dashboard to open the chat modal
  6. Send Admin Reply: Type a response like "Hi! How can I help you today?"
  7. Check Visitor Widget: Within 3 seconds, the admin's reply should appear in the visitor chat (with notification if closed)
  8. Continue Testing: Send messages back and forth to test real-time synchronization

⚡ Real-Time Features

Visitor Widget:

  • Polls for new admin messages every 3 seconds
  • Shows notification badge when new message arrives
  • Auto-scrolls to new messages
  • Works without any authentication

Admin Dashboard:

  • Auto-refreshes client list every 5 seconds
  • Polls for new messages in open conversations every 2 seconds
  • Updates conversation in real-time
  • Shows live message counts and timestamps
