Key Changes Made:

Why This Fix Works:

When you used the relative path /wordpress_support_hub/chatbot-widget.html, the iframe was trying to load from the same domain context as the parent page. This caused the API calls inside the widget to use relative paths that resolved incorrectly.

With the absolute URL, the widget loads in its correct context and the API calls resolve to the right endpoints.
